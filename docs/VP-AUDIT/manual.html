Manual de utilizare

VP Terminal — ghidul complet

Terminal de Volume Profile și Order Flow pentru NQ. Fiecare buton, strat și marker — ce e, cum îl folosești și de ce contează.

📎 Pentru tester: nu trebuie să știi cum e construit tool-ul. Citește Orientarea și Quick Start, apoi folosește secțiunile de referință ca dicționar — cauți un buton, vezi exact ce face.

Limbajul culorilor

Tot tool-ul folosește aceleași culori cu același înțeles. Dacă reții atât, înțelegi jumătate din ecran:

Verde = cumpărare agresivă / bullish Mov = vânzare agresivă / bearish Magenta = POC (prețul cu volum maxim) Auriu = nivelurile de ieri Cyan = HVN (zone de volum mare)

Orientare

Harta ecranului

Ecranul are patru margini de lucru + graficul în centru. Numerele de pe imagine corespund listei de dedesubt.

  1. 1Bara de sus — ce date afișezi: ziua, tipul, intervalul, fusul orar.
  2. 2Carduri statistici — simbol, POC, VAH/VAL, volum total, CVD (delta cumulată).
  3. 3Bara de desen (verticală, stânga) — linii, trend, dreptunghi, fib, măsură, Long/Short.
  4. 4Volume Profile — histograma de volum pe prețuri, suprapusă pe stânga.
  5. 5Graficul — lumânări (verde sus / mov jos), markere, niveluri.
  6. 6Axa de preț (dreapta) — pastile cu POC, VAH, VAL, ultimul preț.
  7. 7Panoul CVD — Cumulative Delta (presiunea netă) de-a lungul sesiunii.
  8. 8Grid statistici — per lumânare: T/s, volum (ΣV), delta (ΔV), Δ%.
  9. 9Bara de straturi — aprinzi/stingi ce vezi, grupat pe categorii.
  10. 10Bara de replay — redai sesiunea ca live (backtesting).

În 2 minute

Quick Start

Cei mai rapizi 5 pași ca să vezi ceva util imediat:

  1. Alege ziua din bara de sus (stânga) — fiecare zi are o etichetă (bullish/range/bearish).
  2. Alege intervalul (ex. 5min pentru structură, 1min pentru scalping).
  3. Alege o vedere din bara de jos → „Order Flow" aprinde un set gândit de straturi.
  4. Apasă Replay (jos-stânga) și derulează cu scrubber-ul — sesiunea se redă ca live.
  5. Treci cu mouse-ul peste markere (bule, triunghiuri, inele) → apare un tooltip cu ce e.

Referință

1Bara de sus

Aici alegi ce date afișezi. Straturile (ce se vede pe grafic) sunt în bara de jos — vezi secțiunea 2.

ZIUA selector zi 📂

Ce e
Ziua de tranzacționare afișată. Eticheta de lângă dată (bullish / range / bearish) îți spune regimul.
Cum
Alegi din listă. Butonul 📂 deschide un fișier de date de oriunde (CSV/Parquet), fără conversie.
De ce
Alegi contextul: o zi de trend pentru continuări, una de range pentru rotații la margini.

Tip Profil / Footprint / Profile Only ⚙

Ce e
Profil = lumânări + Volume Profile suprapus. Footprint = celule bid/ask pe fiecare lumânare. Profile Only = profile per sesiune/zi de-a lungul timpului, fără lumânări.
Cum
Comuți din dropdown. ⚙ de lângă = setări footprint (imbalance).
De ce
Profil pentru structură, Footprint pentru citirea fină a order flow-ului la un nivel, Profile Only ca să compari valoarea pe zile/sesiuni.

Interval 1min … 1D

Ce e
Durata unei lumânări.
Cum
Alegi din listă. Nu resetează poziția/zoom-ul.
De ce
1min = scalping (mai multe detalii, mai multe markere); 5min = structură; superioare = imagine de ansamblu. Markerele se adaptează automat la interval.

Fus România / New York / Chicago / UTC

Ce e
Fusul orar în care se afișează ora (pe axă + crosshair).
Cum
Alegi din listă. Se calculează corect vara/iarna (DST) automat.
De ce
România (implicit): 16:30 = deschiderea NY. Schimbă doar afișarea — calculul intern rămâne în UTC.
